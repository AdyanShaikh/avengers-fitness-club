# Avengers Fitness Club

Production-ready React 19 + Vite website for Avengers Fitness Club, Upvan, Thane West.

## Included

- Responsive fitness-club landing experience
- Classes: Gym, CrossFit, Zumba and Yoga
- Membership renewal interface
- Trainer/coach availability placeholder state
- Trial-request flow with local validation
- Contact and Google Maps link
- Mobile navigation and persistent mobile CTA
- Accessible modal states and keyboard-friendly controls
- Local-business SEO-ready structure
- No fabricated trainer profiles, schedules, prices, booking confirmations or payment success
